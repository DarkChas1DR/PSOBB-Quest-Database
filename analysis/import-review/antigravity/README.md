# Antigravity import review archive

These files were published by Antigravity between commits 074ae44 and ec64966. They are preserved for research and comparison, **not verified authoritative data**. The active database does not load them.

Known unsupported claims include universally safe quest flags, extended Qedit appearance selectors, and complete/crash-safe generated quests. Some rows may be correctly extracted; each needs traceable provenance before promotion.

Original paths are retained below this directory. See [repair audit](../../audit/antigravity-review.md) and [coverage checklist](../../../../DATABASE-COVERAGE.md). Generator source is preserved in repository history at ec64966 and is intentionally not hosted here.
