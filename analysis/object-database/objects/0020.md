## Supporting constructor and parameter documentation

### TOSwitchItem

[Source](../../quest-knowledge/reference/server-source/Map.cc#L1005); BB area mask: 0x00006FFC3FFF07FF.

```text
Item-detecting floor switch. Params:
param1 = radius
param4 = switch flag number
param5 = item type:
0 or any value not listed below = any item
1 = weapon
2 = armor
3 = shield
4 = unit
5 = mag
6 = tool
7 = meseta
param6 = item amount required minus 1 (0 = 1 item, 1 = 2 items, etc.); for tools and meseta, each dropped item
counts for its stack size

```
