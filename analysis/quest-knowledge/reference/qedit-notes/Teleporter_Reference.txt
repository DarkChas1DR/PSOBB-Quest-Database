Phantasy Star Online Custom Quest Development Reference
======================================================
Topic: Teleporter IDs, Floor IDs, Map Selectors, and Warp Objects
Location: Qedit/Information/Teleporter_Reference.txt
------------------------------------------------------

In PSO quest editing (via Qedit and Quest ASM scripting), teleportation is handled using three distinct methods:
1. Object 002 (Teleporter) - Used to transition players between different floors (e.g., Forest 1 -> Forest 2).
2. Object 003 (Warp) - Used to teleport players to a precise X/Y/Z coordinate on the same floor.
3. Script Command: set_mainwarp - Used in the script (.bin) to configure the target destination of the main Pioneer 2 teleporter.

================================================================================
2. OBJECT 002: TELEPORTER (FLOOR-TO-FLOOR TRANSITION)
================================================================================
Place this object in Qedit when you want a standard portal to send players to another floor (e.g., placing a teleporter in Forest 1 that warps players to Forest 2).

Qedit Object Properties (Unique Arguments):
-------------------------------------------
Arg Index | Parameter Name     | Description & Values
----------+--------------------+------------------------------------------------
Unique (1)| Area Number        | Target Area ID (from the index table in Section 1).
          |                    | Example: Set to 2 if warping to Forest 2.
Unique (2)| Color Blue         | 1 = Blue portal, 0 = Not blue.
Unique (3)| Color Red          | 1 = Red portal, 0 = Not red.
Unique (4)| Floor Number       | The target floor index in your quest's active 
          |                    | floor list (usually matches the Area Number).
Unique (5)| Display Number     | Text label index (usually left default).
Unique (6)| No Display Number  | Must be set to 1 to render a red warp portal.

Example: Teleporter in Forest 1 (Floor 1) going to Forest 2 (Floor 2)
- Unique (1) Area Number: 2
- Unique (2) Color Blue: 1 (makes it blue)
- Unique (3) Color Red: 0
- Unique (4) Floor Number: 2
- Unique (6) No Display Number: 0

================================================================================
3. OBJECT 003: WARP (SAME-FLOOR PRECISION TELEPORT)
================================================================================
Use this green warp cylinder if you want a warp on a floor to send players to a specific location on the same floor.

Qedit Object Properties (Unique Arguments):
-------------------------------------------
Arg Index | Parameter Name     | Description & Values
----------+--------------------+------------------------------------------------
Unique (1)| Destination X      | Target X coordinate. (Note: Must be offset by +10 in Qedit)
Unique (2)| Destination Y      | Target Y coordinate (height).
Unique (3)| Destination Z      | Target Z coordinate. (Note: Must be offset by +10 in Qedit)
Unique (4)| Destination Rot Y  | Y-axis rotation direction of the player after warp.

================================================================================
4. QUEST SCRIPT (.BIN) ASM TELEPORT COMMANDS
================================================================================
To configure floor destinations or warp functionality at the script level:

A. set_mainwarp <floor_id>
--------------------------
Sets the warp destination for the central Pioneer 2 teleporter.
Example (Warp to Forest 1):
  arg_pushl                       0x00000001
  set_mainwarp                    ... 0x1

B. bb_map_designate <area_id>, <map_id>, <unk>, <unk>, <unk>
------------------------------------------------------------
Declares which maps are loaded for the active floors in the quest.
Example (Designating Forest 1 & Forest 2):
  bb_map_designate                0x00, 0x00, 0x00, 0x00, 0x00   ; Floor 0 = Pioneer 2
  bb_map_designate                0x01, 0x01, 0x00, 0x00, 0x01   ; Floor 1 = Forest 1 (Map variation 1)
  bb_map_designate                0x02, 0x02, 0x00, 0x00, 0x01   ; Floor 2 = Forest 2 (Map variation 1)
