## Validation and limits

- Byte-identical decompressed script roundtrips: 26 / 47 variants.
- Alignment-only roundtrip differences: 21 variants. These preserve script bytes and label tables, adding 1–3 zero bytes before the table and updating header offsets/size. They are not byte-identical files.
- Enemy counts include NPCs and constructor records; they are not kill counts.
- Script references include callbacks and registrations, not just calls. Dynamic targets are not fully resolved.
- Header and filename quest IDs are retained separately. Language variants are compared; identical maps do not prove identical script behavior.
- Newserv assembly text is not directly promised to import into Qedit.
